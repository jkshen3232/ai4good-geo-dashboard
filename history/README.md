比对历史

本目录保存 GEO 周复测的汇总对照，只含平台指标和逐条评分，不含模型原始回答全文。

- `history.csv` — 各期、各平台汇总（追加写入，不覆盖旧行）。
- `history_prompts.csv` — 各期、各平台、各 prompt 的提到 / 准确度 / 混淆 / 第一方引用（追加写入）。
- `2026-11-25_weekly_diff.md` — 2026-11-25 补跑对照 2026-11-22 基线的中文说明。

`history.csv` 中 `prompts_run` 是计入提到率分母的条数（已回答 + 拒答）。`gated` 为登录墙条数；验证码或账号问题未跑的条数见同期周报，不把登录墙当成提到率下降。

11-25 的豆包、Kimi 属于登录态轨道，因账号已登出全部未测，行在 `history.csv` 中 `mode=logged_in_core`、`prompts_run=0`。
